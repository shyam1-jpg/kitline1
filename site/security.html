Security

How Kiteline protects customer data.

Transport & hosting

  • HTTPS — traffic encrypted in transit on kiteline.uk and the hosted app.
  • Cloud hosting — application and database hosted on reputable UK/EU infrastructure providers.

Accounts & access

  • Password hashing — passwords stored using industry-standard hashing (not plain text).
  • Role-based access — owner, manager, and staff permissions per kitchen.
  • Company isolation — each customer organisation has a private workspace; data is not shared between companies.
  • 2FA — optional two-factor authentication for student accounts.

Data backup & deletion

Operational backups are retained for disaster recovery (typically 30–90 days depending on environment). Account closure requests are processed within a reasonable period — see Privacy Policy.

Reporting issues

Report suspected vulnerabilities to contact@kiteline.uk. Do not publicly disclose active issues before we respond.

B2B customers

Data Processing Agreement and sub-processor list available on request — see Privacy Policy.
